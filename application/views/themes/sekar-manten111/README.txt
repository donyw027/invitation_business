ROYAL JAVA HERITAGE — Wedding Invitation Theme

Cara pasang:
1. Backup file tema lama.
2. Upload index.php ini ke folder tema/view yang sama.
3. Struktur variabel PHP, RSVP, wishes, map, gallery, gift, dan music_url tetap mengikuti template floral asli.
4. Musik tetap berasal dari database: $project->music_url.
5. Tombol Buka Undangan memicu musik agar kompatibel dengan kebijakan autoplay browser HP.

Catatan:
- Tema memakai Bootstrap Icons/Bootstrap dan asset eksternal yang sudah digunakan template awal.
- Background dekoratif memakai URL Unsplash; hero utama tetap memakai hero_image dari database.
- Uji dahulu di staging sebelum mengganti tema produksi.
