JAVA ESSENCE v1.0
Modern Sacred Javanese Editorial Wedding Theme

INSTALL:
1. Backup index.php tema lama.
2. Upload index.php ini ke folder view tema yang sama.
3. Tidak mengubah controller, tabel, atau endpoint.

FITUR TETAP:
- Music dari $project->music_url
- RSVP ke rsvp/store
- Wish ke wish/store
- Gallery, gift, maps, countdown dan guest slug tetap
- Nama tamu URL: ?to=Bapak%20Andi%20dan%20Keluarga

CATATAN:
Font dan icon memakai CDN sehingga server perlu koneksi internet saat halaman dibuka.
