NAWASENA JAVA — Editorial Javanese Wedding Theme

Cara pasang:
1. Backup index.php tema lama.
2. Upload index.php ini ke folder view tema.
3. Semua data tetap mengambil dari $project, $galleries, $wishes, $guest, dan endpoint RSVP/Wish yang sama.

Nama tamu dari link:
https://domainanda.com/link-undangan?to=Budi%20dan%20Keluarga

Nama akan tampil pada cover serta otomatis mengisi nama RSVP dan ucapan.
Apabila sistem Anda sudah memakai guest slug/controller, variabel $guest_name tetap menjadi prioritas.

Musik:
Tetap mengambil dari $project->music_url. Tombol on/off muncul hanya jika URL musik tersedia.
